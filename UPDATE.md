# MAXund Native: Undetect 2

Версия APK: `26.34.1-undetect.2`, versionCode `6857`, Android 13+.
База и пакет прежние: MAX/MIN 26.34.1, `ru.oneme.app`. Подпись — тот же локальный ключ разработки, что у предыдущего APK MAXund Native. Это экспериментальная версия.

## Новая вкладка

**Настройки MAXund → Undetect · Конфиденциальность.** Кнопка добавлена над исходным экраном настроек. Остальной интерфейс и исходные модули входа/2FA/«Цифрового ID» сохранены.

Все новые переключатели по умолчанию **выключены**. Прежние ограничения разрешений и отзыв камеры/микрофона сохраняются независимо от них.

| Настройка | Что делает |
| --- | --- |
| Инкогнито | Объединяет четыре следующие настройки; отдельные переключатели сохраняют свои значения |
| Скрывать активность | Подменяет булево поле `interactive` на `false` в исходящих запросах; сокет и heartbeat не отключаются |
| Не отправлять прочтение | Перехватывает `CHAT_MARK` (50) только с типом `READ_MESSAGE` до очереди отправки; `SET_AS_UNREAD` и `READ_REACTION` не меняются |
| Скрывать набор текста | Блокирует исходящие `MSG_TYPING` (65), кроме распознанных аудио/видео/record-сигналов |
| Скрывать запись голосового | Блокирует `MSG_TYPING` с AUDIO/VOICE/VIDEO/RECORD в типе; отправка самого сообщения не блокируется |
| Отправить прочтение вручную | Показывает накопленные блокировки по чатам; после отдельного подтверждения передаёт выбранный запрос штатному транспорту |
| Исключения для чатов | Разрешает прочтение и индикаторы в выбранных чатах; глобальный статус онлайн исключениями не меняется |
| Подтверждать исходящий звонок | Спрашивает подтверждение для маршрутов личных и групповых звонков `cl1`/`dl1`, включая голос/видео; входящие звонки и другие маршруты не перехватываются |
| Блокировать при уходе в фон | Отдельный закрытый экран с BiometricPrompt: биометрия или PIN/пароль системной блокировки Android; свой отдельный PIN приложения не создаётся |
| Скрывать текст уведомлений | Заменяет содержание новых уведомлений, удаляет историю, изображения/large icon, действия и нестандартные представления; уже показанные уведомления не переписываются |
| Отключать автозагрузку медиа | Пропускает DownloadAttachesWorker с причиной AUTOLOAD; ручные загрузки и другие причины не блокируются |

## Существенные ограничения

- `interactive=false` **не гарантирует «не в сети»**. Сервер может выводить присутствие по соединению и другим действиям. Инкогнито не обеспечивает анонимность перед сервером MAX. Для применения к начальной синхронизации перезапустите приложение после изменения настройки; выход из аккаунта не нужен.
- Скрытие прочтения и индикаторов реализовано на найденных точках отправки. Полного анализа всех путей отправки, бинарных библиотек и протокола нет. Работу с реальным собеседником и сервером в этой версии разработчик не проверял.
- Подавленный запрос завершается локальной ошибкой `undetect.suppressed`, а не фиктивным подтверждением сервера. Исходный клиент может сохранять локальные непрочитанные, повторять локальные попытки или записывать ошибку в свой журнал.
- Ручное прочтение означает передачу в очередь, а не получение подтверждения от сервера. В памяти хранится максимум 100 последних запросов по чатам; после завершения процесса они теряются. При новом открытии чата блокировка может появиться снова. Отключение инкогнито само по себе накопленные запросы не отправляет.
- Список исключений заполняется при блокировке прочтения. Чаты пока обозначены внутренними номерами, без загрузки их названий. Исключения сохраняются в локальных настройках.
- Экран блокировки включается при возвращении после зарегистрированного ухода в фон (порог 1,2 секунды). Это экран доступа, не дополнительное шифрование базы. Устройство должно иметь системную блокировку. Быстрый переход между экранами приложения не блокирует его.
- Действия уведомлений (например быстрый ответ) при скрытии уведомлений удаляются. Другие пути отображения, например системный экран входящего звонка, не считаются скрытыми уведомлениями.
- Ограничение автозагрузки относится к найденному worker. Аватары, миниатюры, другие загрузчики и уже запущенные задачи могут продолжать загружаться.
- Фоновые звонки по прежней политике отзыва камеры/микрофона прекращаются. Откат к старому APK с меньшим versionCode стандартным обновлением Android не выполняется.

## Проверка

Полная сборка и аудит APK прошли. Точный APK установлен как обновление в выделенный Android 13 эмулятор; экран ввода телефона создан без свежих crash-записей. После ухода в фон камера и микрофон стали `granted=false`, процесс завершился. Все 15 выбранных тестов на Android 13 прошли без пропусков (11 новых и 4 прежних lifecycle-теста).

APK SHA-256: `09da37bbadfd0f68a5191b688f2c48b6d7b88d4045c91924d5dee1cdf7701718`.

Запуск полного набора для этой версии:

```bash
bash scripts/check-native.sh
```

Сборщик проверяет закреплённые инструменты/исходный архив, применяет оба патча, компилирует PrivacyLifecycle и Undetect, собирает все четыре DEX, подписывает и проверяет APK. Аудит проверяет манифест, DEX, версию и наличие новых точек вызова.

Robolectric Android 13 проверяет политику протокола, исключения, ручную передачу запроса, подтверждение/отмену звонка, маскирование уведомлений, отделение AUTOLOAD от ручных загрузок, построение экрана и прежний отзыв медиаразрешений. Протокольные fixture-классы в тестах проверяют отражение и callbacks, но не эмулируют сервер MAX.

Предыдущий APK пользователь проверил успешным входом. Это не результат проверки входа новой версии. Реальный вход, переписка, статусы для другого аккаунта, 2FA, звонки, блокировка на физическом устройстве и возрастной QR новой версии требуют отдельной проверки владельцем. Не отправляйте разработчику SMS-коды, пароли и токены.

Дополнительно на эмуляторе запущена приватная Activity настроек через root тестового гостя: созданы все 9 переключателей, есть измеренные элементы, свежих crash-записей нет. Это не проверка навигации из авторизованного штатного экрана настроек и не полный визуальный тест. Отчёты: `native/EMULATOR-RESULT.json`, `native/UNDETECT-EMULATOR.json`, `native/UNDETECT-TESTS.json`.

Новые файлы: `native/privacy/Undetect.java`, `UndetectActivity.java`, `UndetectLockActivity.java`, `native/undetect_patch.py`. Изменены lifecycle, сборщик, аудит и тесты.

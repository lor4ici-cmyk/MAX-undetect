# MAXund Native — проверка первой сборки 26 октября 2026

Это исторический отчёт версии 1. Для Undetect 2 см. [UPDATE.md](UPDATE.md) и `native/UNDETECT-TESTS.json`; вход новой версии этим отчётом не подтверждается.

Исходник: MIN Safe MAX, ad2568aba95a16fa140713a7ae273dc7e4b004d6, версия 26.34.1.
APK SHA-256: `85e1eafd09c4589d5cdad8a573fd1b0e84ceae30f3d3252634c991b8366a4ec2`. Минимальная версия Android — 13.

## Пройденные проверки

- Полная сборка из smali официальным Apktool 2.12.0; готовые upstream DEX не использованы.
- Проверены исходный архив и инструмент по SHA-256, подпись APK, 16KB zip alignment.
- Проверены внутренние SHA1/Adler32 всех четырёх DEX.
- В собранном манифесте отсутствуют удалённые разрешения и Tracer startup providers.
- В скомпилированном коде MyTracker init/trackEvent/flush возвращаются без выполнения
  операций; DailyAnalyticsWorker только возвращает успешное завершение.
- Приложение регистрирует PrivacyLifecycle; запрещённые проверки canRequestPackageInstalls
  в DEX отсутствуют. Их удаление исправило обнаруженный реальный SecurityException запуска.
- Четыре теста PrivacyLifecycle на Robolectric API 33: все прошли, без пропусков.
- APK с указанным SHA-256 установлен в чистый Android 13 x86_64 эмулятор.
- Создан штатный экран ввода телефона, процесс живой, свежих Java crash-записей нет.
- После выдачи CAMERA и RECORD_AUDIO в тестовом госте и ухода на Home оба разрешения
  перешли в granted=false, а процесс завершился. Проверка прошла на третьем опросе.
- Ни номер телефона, ни SMS, ни пароль, ни действительный аккаунт не использовались.

## Что найдено и исправлено в ходе проверки

- Удаление REQUEST_INSTALL_PACKAGES само по себе приводило к SecurityException
  в eager capability query. Все три вызова заменены на false без возврата разрешения.
- Немедленный killProcess после асинхронного revokeSelfPermissionsOnKill оставлял
  права в ONE_TIME/granted=true: проверка завершения отзыва за 60 секунд не прошла.
  В финальной сборке перед завершением оставлено 5 секунд для доставки запроса
  PermissionController, проверка повторена на новой чистой установке и прошла.

## Ограничения проверки

- Нет KVM: эмулятор работает медленно, периодически появляется ANR системного UI.
  am start -W иногда возвращает timeout; готовность оценивалась по живому процессу,
  созданной native view hierarchy ввода телефона и отдельному crash-буферу.
  Полная визуальная проверка интерфейса и интерактивного входа не выполнена.
- Не проверены получение кода с сервера, реальный вход, 2FA, сообщения, звонки,
  фактическая запись аудио/видео и предъявление возрастного QR на кассе.
- Исходные модули этих функций сохранены, но это не доказательство их работоспособности.
- Полного аудита всех native-библиотек и smali-кода нет; отсутствие всего сбора
  данных не доказано, серверный сбор данных не устранён.
- Настройки cloud-среды сохраняются отдельным черновиком; публикация и восстановление
  в новой задаче не проверялись.

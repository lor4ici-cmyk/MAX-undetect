# Что изменено в MAXund Native 26.34.1

База: MIN Safe MAX, commit `ad2568aba95a16fa140713a7ae273dc7e4b004d6`.
Ниже перечислены изменения MAXund относительно этой базы, а не полный аудит MAX.

## Аналитика и фоновые компоненты

- `MyTracker.initTracker`, обе перегрузки `trackEvent` и `flush` заменены возвратом без выполнения действий. Сама библиотека частично остаётся в APK.
- `DailyAnalyticsWorker` возвращает успешное завершение без исходного сбора статистики разрешений.
- Удалены провайдеры и метаданные автоматического запуска Tracer. Это не доказательство удаления всех остальных путей его запуска.
- Отключены найденные Boot-receiver; убраны типы foreground-service `location` и `mediaProjection`.
- Запрещено стандартное резервное копирование приложения в манифесте (`allowBackup=false`, `fullBackupContent=false`).

## Удалённые разрешения

| Назначение | Разрешения |
| --- | --- |
| Контакты | `READ_CONTACTS`, `WRITE_CONTACTS` |
| Геопозиция | `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` |
| Широкое чтение медиатеки | `READ_MEDIA_AUDIO`, `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO` |
| Старый доступ к общему хранилищу | `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE` |
| Запуск после загрузки | `RECEIVE_BOOT_COMPLETED` |
| Установка APK | `REQUEST_INSTALL_PACKAGES` |
| Исключение из энергосбережения | `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` |
| Фоновая демонстрация экрана | `FOREGROUND_SERVICE_MEDIA_PROJECTION` |
| Рекламный ID | `com.google.android.gms.permission.AD_ID` |
| Install Referrer | `com.google.android.finsky.permission.BIND_GET_INSTALL_REFERRER_SERVICE` |

Три вызова `canRequestPackageInstalls()` заменены на `false`, чтобы удаление разрешения не вызывало падение.
Удаление разрешений ограничивает соответствующие Android API, но не доказывает отсутствие других способов получения данных.

## Камера, микрофон и защита экрана

- Разрешения `CAMERA` и `RECORD_AUDIO` сохранены для штатных функций. Автоматического предоставления прав патч не выполняет; пользователь управляет разрешениями Android.
- Через 1,2 секунды после остановки всех Activity останавливаются два call-сервиса и, если камера/микрофон разрешены, вызывается Android 13 `revokeSelfPermissionsOnKill`.
- Завершение собственного процесса откладывается ещё на 5 секунд для доставки асинхронного запроса системе. Возвращение в приложение отменяет собственный таймер завершения. Срок фактического отзыва определяет Android.
- На эмуляторе Android 13 проверено: после ухода в фон оба разрешения стали `granted=false`, процесс завершился.
- `FLAG_SECURE` ограничивает стандартные скриншоты, запись экрана и превью окон. Это защита отображаемого содержимого, а не доказательство отсутствия сбора данных внутри приложения.

**Последствия:** фоновые звонки прекращаются; импорт адресной книги и широкая внутренняя галерея ограничены; штатная демонстрация экрана ограничена.

## Что сохранено

Исходный интерфейс, протокол входа, код 2FA, чатов, звонков и «Цифрового ID»; пакет `ru.oneme.app`, версия 26.34.1. Название — MAXund Native; минимальный Android — 13. Сохранённый модуль не означает проверенную работоспособность всех сценариев.

Владелец подтвердил успешный вход на телефоне. Локально проверены сборка, подпись, DEX/манифест, старт экрана телефона, четыре теста PrivacyLifecycle и отзыв медиаразрешений. Полная проверка переписки, звонков, 2FA и возрастного QR не выполнена.

## Чего обещать нельзя

Полного аудита smali, native-библиотек и сетевого трафика нет. Отключены перечисленные точки запуска аналитики; отсутствие всех остальных механизмов сбора данных не подтверждено. Сервер MAX продолжает получать данные, передаваемые клиентом. Сессия и локальный кэш сохраняются по логике исходного клиента.

APK подписан ключом разработки, не официальным ключом MAX. Он не обновляет установку с другой подписью. Ключ подписи не включён в публичные исходники.

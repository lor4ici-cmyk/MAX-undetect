# MAXund Native — Android 13+

**Экспериментальная модификация MAX 26.34.1. Полное отсутствие слежки не гарантируется.**

[Скачать проверенный APK, 128 МБ](https://gofile.io/d/G0ioaWtZ) ·
[Релизы GitHub](https://github.com/lor4ici-cmyk/MAX-undetect/releases) ·
[Полный архив исходников, 99 МБ](https://gofile.io/d/aKCwUMMg) · [Подробные изменения](CHANGES.md) · [Публикация и исходники](SOURCE-AND-RELEASE.md)

Владелец сообщил об успешном входе на своём телефоне. Это пользовательская проверка:
независимая проверка входа, 2FA, звонков и возрастного QR разработчиком не проводилась.


Новая ветка сборки на основе [MIN Safe MAX](https://github.com/Rise0x00/MIN-Safe-MAX),
коммит `ad2568aba95a16fa140713a7ae273dc7e4b004d6`, исходная версия MAX 26.34.1.
Сохраняет исходные интерфейс, нативный протокол входа, 2FA, звонки, медиа и модуль
«Цифрового ID». Старый самостоятельный клиент 0.1–0.3 в `app/` остаётся для истории
и не является новой нативной сборкой. Его описание: [PROTOTYPE.md](PROTOTYPE.md).

## Сборка в cloud-среде

```bash
cd /workspace/MAX-undetect
python3 scripts/bootstrap_cloud.py
bash scripts/check-native.sh
```

Выход: `native/work/MAXund-native.apk`. Инструменты, архивы и входной исходный
код проверяются по фиксированным SHA-256; build повторно собирает все DEX из smali,
не используя готовые DEX из upstream/build. Секретов аккаунта для сборки не нужно.
Тестовый ключ подписи находится вне репозитория в `/workspace/toolchains/android-user/debug.keystore`.
Его нужно сохранить для совместимости обновлений. Это не подпись владельца MAX.

## Изменения относительно MIN

- Проверка возможности установки пакетов возвращает false без вызова защищённого API,
  чтобы отсутствие REQUEST_INSTALL_PACKAGES не приводило к падению при запуске.
- Название значка — MAXund Native, чтобы отличать от старого прототипа MAXund. Пакет и версия исходного клиента сохранены для совместимости.
- Отключены MyTracker.initTracker, trackEvent и flush, а также DailyAnalyticsWorker,
  который собирал статистику разрешений.
- Удалены провайдеры и метаданные автоматического запуска Tracer.
- Убраны разрешения на контакты, геолокацию, чтение всей медиатеки, рекламный ID,
  установку пакетов, запрос исключения из энергосбережения, автозапуск и демонстрацию экрана.
- Камера и микрофон оставлены для штатных функций; автоматического предоставления прав нет.
- После ухода всех Activity в фон завершаются call-сервисы и через Android 13 API
  планируется отзыв выданных CAMERA/RECORD_AUDIO. Перед завершением своего процесса
  оставляется 5 секунд для асинхронного запроса PermissionController; при возвращении
  в приложение отложенное завершение отменяется. Само применение системного отзыва
  определяется Android. Переход между экранами приложения не считается выходом.
- FLAG_SECURE защищает окно от стандартных снимков экрана/эскизов задач.

Фоновый звонок при такой политике прекращается. Демонстрация экрана и импорт всей
адресной книги недоступны. Выбор ранее сделанных фото из внутренней галереи приложения
может быть ограничен, поскольку широкие разрешения чтения медиатеки удалены.

## Установка и реальные проверки

**Пакет: `ru.oneme.app`.** Он совпадает с официальным MAX и некоторыми модами,
но подпись другая. Поверх установленной версии с другой подписью APK не установится.
Сборщик не удаляет приложения и данные телефона. Не удаляйте текущий MAX без понимания,
как сохранить нужные данные и восстановить доступ к аккаунту. Для первой проверки
предпочтительно отдельное тестовое устройство без установленного пакета `ru.oneme.app`.
Со старым прототипом MAXund (`app.maxund`) это разные пакеты.

Модуль «Цифрового ID» сохранён, но действительный QR выдаёт официальный сервис
при наличии подтверждённого аккаунта и доступности функции. Работу на конкретной
кассе, совместимость входа, 2FA и звонков необходимо проверять на реальном аккаунте.
Локальные проверки сборки не заменяют такой проверки. См. [VALIDATION.md](VALIDATION.md).

Это модифицированный сторонний клиент, а не доказанно свободное от любого сбора данных
приложение. Аналитические библиотеки частично остаются в исходниках и APK; отключены
конкретные перечисленные точки запуска. Полный аудит всего нативного и smali-кода
не выполнен. Сервер MAX по-прежнему получает необходимые данные аккаунта, переписку
и сетевые метаданные. Нативный клиент сохраняет сессию и локальные данные по своей
исходной логике; прежнее утверждение прототипа «всё только в RAM» здесь не действует.

## Дополнительная проверка в подготовленной cloud-среде

Для эмулятора сохранены Android 13 x86_64 image, emulator и AVD MAXund в
`/workspace/toolchains`. Запуск: `bash native/start-test-emulator.sh`. Аппаратного
ускорения в текущей среде нет, загрузка может занимать несколько минут; процессы
не сохраняются в snapshot. Для обращения к гостю используется adb-shell по
localhost:5581, поскольку обычный host ADB требует недоступную запись в корень
домашнего каталога. Временное отключение ADB-auth относится только к этому чистому
локальному тестовому гостю, не к телефону пользователя и не к авторизации MAX.

Проверка (только на выделенном пустом AVD, без реального аккаунта):
`PYTHONPATH=/workspace/toolchains/py-adb python3 native/smoke_existing_emulator.py 5581`.
Флаг `--fresh` удаляет прежнюю тестовую установку в AVD MAXund; не используйте его
для сохранённых данных. Отчёт: `native/work/emulator-smoke.json`.

Проверка с настоящим аккаунтом требует действий владельца на своём устройстве.
Не отправляйте разработчику номер, SMS-коды, пароли 2FA и токены.

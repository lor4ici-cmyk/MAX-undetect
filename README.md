# MAXund Native

Экспериментальная Android-сборка на основе [MIN Safe MAX](https://github.com/Rise0x00/MIN-Safe-MAX), commit `ad2568aba95a16fa140713a7ae273dc7e4b004d6`, версия 26.34.1. Требуется Android 13 или новее.

APK и архив проекта находятся в разделе [Releases](https://github.com/lor4ici-cmyk/MAX-undetect/releases).

Изменены отдельные разрешения и точки запуска аналитики; добавлен отзыв доступа к камере и микрофону после ухода приложения в фон. Фоновые звонки прекращаются. Полное отсутствие сбора данных не подтверждено.

Проверены сборка, подпись, запуск экрана телефона и отзыв разрешений в Android 13 эмуляторе. Получение SMS, реальный вход, 2FA, сообщения, звонки и возрастной QR на кассе не проверены.

Пакет `ru.oneme.app` подписан ключом разработки и не может обновить официальный MAX с другой подписью. Не удаляйте установленное приложение без сохранения данных.

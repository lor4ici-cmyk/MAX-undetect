# Выбор основы

- WhiteMAX-Mod/whitemaxmod: несколько декомпилированных версий MAX; собственные
  некоммерческие условия. README заявляет отключение инициализации MyTracker.
- nemax-dev/nemax-android: декомпилированный клиент, README прямо предупреждает,
  что GitHub-автосборки устарели и не содержат всех рекламируемых патчей. Модификации
  заявлены под CC BY-NC 4.0. Не выбран из-за предупреждения о неполноте текущей сборки.
- Rise0x00/MIN-Safe-MAX: декомпилированный клиент 26.34.1, Apache-2.0 для модификаций,
  рабочая структура Apktool 2.12.0. README заявляет исправление авторизации; это
  заявление автора, не результат собственной проверки MAXund с реальным аккаунтом.

не являются доказательством отсутствия телеметрии. У MIN обнаружены сохранённые

упрощёнными экранами старого прототипа.
